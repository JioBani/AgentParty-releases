## 주요 변경

### 멤버 탭 안에서 대화와 브라우저를 전환하세요

멤버 탭의 오른쪽 메뉴에서 **브라우저 탭 보기**를 누르면 현재 멤버 탭이 브라우저 화면으로 바뀝니다. 별도 탭으로 이동하거나 새 탭을 만들지 않습니다. 브라우저에서 **대화 탭 보기**를 누르면 같은 탭에 대화가 다시 나타납니다. 웹페이지는 그대로 유지되므로 오가며 확인할 수 있습니다.

![하나의 멤버 탭에서 브라우저를 보는 화면](https://raw.githubusercontent.com/JioBani/AgentParty-releases/main/media/releases/v0.15.0/browser-in-member-tab.png)

### 동시에 보고 싶을 때만 분리하세요

브라우저의 **브라우저 탭 분리하기**를 누르면 같은 탭 그룹에 별도의 브라우저 탭이 생깁니다. 이 탭을 옆 패널로 나누면 멤버와 대화하면서 웹페이지를 함께 볼 수 있습니다. 다시 **멤버 탭과 합치기**를 누르면 별도 탭이 없어지고 기존 멤버 탭에서 브라우저를 볼 수 있습니다.

![멤버 대화와 브라우저를 나란히 연 화면](https://raw.githubusercontent.com/JioBani/AgentParty-releases/main/media/releases/v0.15.0/browser-side-by-side.png)

### 브라우저 작업이 보고 있던 화면을 빼앗지 않습니다

멤버가 페이지를 열거나 조작해도 현재 선택한 탭과 패널이 자동으로 바뀌지 않습니다. 옆 패널에서 대화를 읽는 동안 브라우저의 클릭·입력 결과를 확인할 수 있고, 데스크톱 마우스 포인터도 움직이지 않습니다. 화면 전환은 **보기·분리·합치기**처럼 명시적인 버튼을 사용할 때만 일어납니다.

### Codex CLI의 기존 기능을 그대로 이용할 수 있습니다

AgentParty의 내장 브라우저를 추가했다는 이유로 Codex CLI에서 제공하는 Computer Use나 브라우저 연결 기능을 숨기지 않습니다. 실제 사용 가능 여부는 설치된 Codex CLI와 해당 세션에 연결된 도구 환경에 따릅니다.

## 업데이트 안내

기존에 분리해 둔 브라우저 탭 배치는 유지되며, 원하는 때 **멤버 탭과 합치기**로 전환할 수 있습니다. 파티·세션·설정 데이터의 마이그레이션은 필요하지 않습니다. 앱 내 브라우저의 로그인 상태는 앱을 종료하면 유지되지 않습니다. 클릭·입력·스크린샷에는 해당 브라우저 화면을 앱에 표시해야 합니다.

## 설치

- 자동 업데이트를 사용하려면 `AgentParty-Setup-0.15.0.exe`를 설치하세요.
- `AgentParty-0.15.0.exe`는 설치 없이 실행하는 포터블 버전이며 자동 업데이트를 지원하지 않습니다.
