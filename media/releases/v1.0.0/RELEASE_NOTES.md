## 주요 변경

### 대화와 브라우저를 나란히 보며 작업하세요

멤버가 앱 안에서 전용 브라우저 탭을 열 수 있습니다. 브라우저 탭을 대화 옆 패널로 옮기면 웹페이지를 보면서 멤버와 계속 대화할 수 있습니다. 멤버는 페이지 내용을 읽고, 클릭·입력·스크롤할 수 있으며 이 과정에서 데스크톱 마우스 포인터를 움직이지 않습니다.

![멤버 대화와 전용 브라우저 탭을 나란히 연 AgentParty 1.0](https://raw.githubusercontent.com/JioBani/AgentParty-releases/main/media/releases/v1.0.0/browser-side-by-side.png)

*예시 화면: 왼쪽은 멤버 대화, 오른쪽은 같은 멤버의 앱 내 브라우저입니다.*

### Codex가 만든 파일과 다음 작업을 바로 이어가세요

Codex 답변에 포함된 파일 인용은 긴 내부 표기 대신 파일 이름과 열기/위치 확인 버튼으로 표시됩니다. 제안된 후속 작업도 버튼을 눌러 해당 멤버에게 바로 요청할 수 있습니다.

![Codex 답변의 파일 링크와 후속 작업 버튼](https://raw.githubusercontent.com/JioBani/AgentParty-releases/main/media/releases/v1.0.0/codex-results.png)

*예시 대화로 촬영한 화면이며 실제 사용자 파일이나 작업 내용은 포함하지 않았습니다.*

### 모델 선택과 작업 상태를 다듬었습니다

- 지원되는 Claude Code CLI에서는 **Opus 5.5**를 선택할 수 있습니다. 이 모델은 Claude Code 2.1.280 이상이 필요합니다.
- 멤버 탭을 다시 열 때 탭 배치가 예상과 다르게 바뀌는 문제를 수정했습니다.
- 작업이 진행 중인데 잠시 `idle`로 표시되던 현상을 수정했습니다.

## 업데이트 안내

기존 파티·세션·설정 데이터의 마이그레이션은 필요하지 않습니다. 현재 앱 내 브라우저의 로그인 상태는 앱을 종료하면 유지되지 않습니다.

## 설치

- 자동 업데이트를 사용하려면 `AgentParty-Setup-1.0.0.exe`를 설치하세요.
- `AgentParty-1.0.0.exe`는 설치 없이 실행하는 포터블 버전이며 자동 업데이트를 지원하지 않습니다.
